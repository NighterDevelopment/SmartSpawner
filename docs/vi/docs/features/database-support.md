# Hỗ Trợ Cơ Sở Dữ Liệu

Chọn backend lưu trữ phù hợp mô hình máy chủ:

| Chế độ | Trường hợp sử dụng |
|--------|--------------------|
| `YAML` | Một máy chủ, thiết lập đơn giản |
| `SQLite` | Một máy chủ, hiệu năng tốt hơn YAML |
| `MySQL` | Nhiều máy chủ hoặc lưu lượng cao |

Danh sách spawner liên máy chủ có sẵn trong chế độ `MYSQL` qua `/ss list`.
