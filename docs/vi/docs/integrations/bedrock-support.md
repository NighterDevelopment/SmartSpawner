# Hỗ Trợ Bedrock

Cài cả Geyser và Floodgate khi người chơi Bedrock kết nối không dùng tài khoản Java. SmartSpawner dùng Floodgate để phát hiện người chơi.

```yaml
bedrock_support:
  enable_formui: true
```

Khi bật:

- Người chơi Bedrock nhận form phù hợp thiết bị di động cho các menu spawner được hỗ trợ.
- Người chơi Java tiếp tục dùng inventory GUI.
- SmartSpawner quay về GUI thông thường nếu Floodgate không khả dụng.
