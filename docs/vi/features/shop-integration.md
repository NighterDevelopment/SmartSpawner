# Tích Hợp Cửa Hàng

Bán vật phẩm trực tiếp từ GUI kho spawner với hỗ trợ đầy đủ hệ thống kinh tế.

<CardGrid>

<FeatureCard icon="CircleDollarSign" title="Backend Kinh Tế">

- **Vault**: API kinh tế phổ biến
- **ExcellentEconomy**: Hỗ trợ nhiều loại tiền tệ

</FeatureCard>

<FeatureCard icon="Store" title="Plugin Cửa Hàng">

- EconomyShopGUI / EconomyShopGUI Premium
- ShopGUI+
- zShop

Giá cũng có thể được đặt thủ công trong `sell_integration.yml`.

</FeatureCard>

</CardGrid>

Xem [Cửa hàng và Kinh tế](/vi/docs/integrations/shops/) để biết cách cấu hình, chọn provider và khắc phục sự cố.
