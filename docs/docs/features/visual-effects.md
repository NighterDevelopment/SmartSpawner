# Visual Effects

Give players useful feedback without adding real mob entities.

<CardGrid>

<FeatureCard icon="MessageCircle" title="Holograms">
Floating text displays above spawners showing their type and stack size. Toggle it with `/ss hologram`. Offset, alignment, and shadow are configurable.
</FeatureCard>

<FeatureCard icon="Sparkles" title="Particles">
Optional particle effects appear when spawners are stacked, activated, or generate loot. Each effect can be toggled independently.
</FeatureCard>

<FeatureCard icon="MapPinned" title="Nearby Scanner">
Use `/ss near [radius]` to scan and highlight nearby spawners through walls with glowing BlockDisplay outlines visible only to the player who ran the command.
</FeatureCard>

</CardGrid>
