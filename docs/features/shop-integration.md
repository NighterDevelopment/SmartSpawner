# Shop Integration

Sell items directly from the spawner storage GUI with full economy support.

<CardGrid>

<FeatureCard icon="CircleDollarSign" title="Economy Backends">

- **Vault**: Universal economy API
- **ExcellentEconomy**: Multi-currency support

</FeatureCard>

<FeatureCard icon="Store" title="Shop Plugins">

- EconomyShopGUI / EconomyShopGUI Premium
- ShopGUI+
- zShop

Prices can also be defined manually in `sell_integration.yml`.

</FeatureCard>

</CardGrid>

See [Shops and Economy](/docs/integrations/shops/) for configuration, provider selection, and troubleshooting.
